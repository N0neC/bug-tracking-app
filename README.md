# 🪲 Bug Tracking App by Mrutunjaya Senapati

## Overview
This **Bug Tracking App** is a Python-based tool developed by **Mrutunjaya Senapati** to help you track your **bug bounty progress**. Log the bugs you find each day, visualize your progress through interactive graphs, and store your data in a CSV file for future reference.

### Features
- Track your bug bounty findings on a daily basis.
- Visualize your progress over time with a bar graph.
- Store bug counts in a CSV file for record keeping.
- Interactive, easy-to-use graphical interface built using **Tkinter**.

## Installation

### Prerequisites:
Ensure you have **Python 3** installed on your system. You can download it [here](https://www.python.org/downloads/).

### Steps:
1. **Clone the repository**:
   ```bash
   git clone https://github.com/N0neC/bug-tracking-app.git
   cd bug-tracking-app```

2. **Install required dependencies:**
``pip install -r requirements.txt``
4. **Run the app:**
``python app.py``

##Usage

Once the app is running, you can:

    Log Bug Counts: Enter the number of bugs you've found each day.

    View Recorded Data: Check all your past bug counts and view them in a color-coded list.

    Track Progress: Visualize your daily bug counts through a bar graph.
