# 🪲 Bug Tracking App by Mrutunjaya Senapati

## Overview
This **Bug Tracking App** is a Python-based tool developed by **Mrutunjaya Senapati** to help you track your **bug bounty progress**. Log the bugs you find each day, visualize your progress through interactive graphs, and store your data in a CSV file for future reference.

### Features
- Track your bug bounty findings on a daily basis.
- Visualize your progress over time with a bar graph.
- Store bug counts in a CSV file for record keeping.
- Interactive, easy-to-use graphical interface built using **Tkinter**.
